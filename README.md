## 🚀 Live Demo
Simply open `index.html` in any modern web browser — **no build tools, bundlers, or dependencies required!**

## 🛠️ Built With
- **Tech Stack:** HTML5 Canvas, Vanilla JavaScript, CSS3 Glow Effects
- **Architecture:** Zero-dependency, single-file clean frontend

## ✨ Key Features
- ✨ **Interactive cursor ripple distortion**
- ✨ **Neon emerald and violet color toggles**
- ✨ **Reactive audio pulse simulation**
- ✨ **Custom binary and katakana character streams**

---

## 📥 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/AhadProCoder/cyberpunk-matrix-rain.git
   ```
2. Open `index.html` in Chrome, Firefox, Safari, or Edge.
3. Enjoy the visuals and interactive physics!
